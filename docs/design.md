# 青芽：产品与交互设计

2026-11-06。基于 [九款竞品桌面调研](research.md)，结合用户明确提出的「运动/英语 100 次」与完全自定义项目需求。

## 两种记录，不混淆

日常习惯回答「在计划的日子做到了吗」；百次挑战回答「一共做了多少次」。前者有日期、星期计划、数量目标；后者是 100 个独立完成事件，不要求每天，同一天无限定一次，不设连续天数。五个底部入口：今天、百次、花园、趋势、我的。

用户的首条数据由用户创建；空状态不伪造历史。英语、跳绳等可自定义名称，模板只是省输入。每个挑战独立存储 100 格及备注。一个完成格对应一次投入，备注可写实际数量，但不会把「跳绳500下」自动当成500次打卡。

## 百次成就卡

- 顶部项目切换条；随时新建多张卡片。
- 深绿进度卡：大数字、100 次分母、环形比例、项目名称图标。
- 10×10 网格：未完成显示序号；完成有对勾和绿色填充，不仅依赖颜色区分。
- 一键按钮选择最小空格；不会填入已经完成的格子，也不会超过100。
- 点任意格子进入大尺寸操作面板，含前后格导航、完成时间、备注、完成/保存/撤销。
- 10列在常见手机上单格不足48dp，因此网格仅负责精细选择，不以小格直接完成不可逆操作；大尺寸主按钮和面板导航提供替代操作。仍需实际用户验证视觉/操作障碍人群使用体验。
- 撤销需确认，清除这格时间和备注，其他格子不动。再次完成该格会得到新时间。
- 收藏保留所有记录；可重新开启。百次完成后卡片仍可查看或纠正。

## 视觉与动画

暖纸白 #F5F5ED、森林绿 #28573F、浅芽绿 #D7E8AA，少量陶土色强调。较大的留白、圆角卡片、清晰中文层级。树木使用原创 Canvas 几何插画，没有下载外部图形资源。

- 页面淡入220ms/淡出120ms；减少动画时为0。
- 百次格子填色260ms，勾号路径描边360ms。
- 数字计数短淡变；第1次/每10次启动1200ms有限粒子庆祝。
- 100次显示永久成就说明，庆祝结束仍保留成果。
- 树木随累计成长轻弹；没有持续的摇摆或粒子循环。
- 减少动画可关闭庆祝和大多数过渡；Compose 响应系统动画比例设置。

交互保存与动画分离：数据成功落盘才更新统计/庆祝；下载、写文件在IO线程。防重复点击的主按钮在本次写入期间禁用。所有成长从记录重算，撤销不会留下幽灵积分。

## 数据与时间规则

- 习惯记录键 = habitId + 本地日期。日目标完成是amount≥target，不会因多点获得重复奖励。
- 编辑目标/重复日会写入当天生效的Plan，过去沿用旧Plan。当天修改按新目标计算。
- 归档从当天开始不再参与计划分母，既有完成仍计入累计叶子。
- 百次格子键 = challengeId + index(0..99)；时间使用UTC Instant记录，显示时转当前时区。
- 月完成率只统计当月截至今天的应执行计划；百次挑战不混入日历完成率。
- 花园累计叶子合并两种真实完成事件；中断不会扣除历史。

## 首版明确边界

没有云同步、桌面组件、专注计时、社交、排行榜或订阅。提醒是全局每日一次，系统可能延迟；不是每个习惯分别设多个闹钟。百次卡可查看但暂不提供图片分享导出，数据备份完整包含它。更新是自动检查、主动下载、系统确认，不是强制/静默更新。
