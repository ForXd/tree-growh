# 青芽隐私说明

生效日期：2026-11-06。

青芽由 ForXd 开发，源代码公开于本仓库。无需账号，不含广告、统计或崩溃遥测 SDK。

习惯、星期计划、每日数量、百次挑战、完成时间、备注和偏好仅保存在应用私有目录。应用不会上传这些内容。自动云备份与设备迁移已禁用。导出由用户通过 Android 文件选择器选择位置，JSON 为明文；导入时先验证，再由用户确认替换。卸载会删除本地数据。

自动更新开启时，应用在前台最多每天检查一次固定 GitHub Release 清单；手动检查可立即发起。GitHub 接收到普通 HTTP 请求信息，例如 IP 地址。请求不包含习惯或打卡记录。用户可以关闭自动检查。下载只从项目的 GitHub 发布资产及其官方 HTTPS CDN 获取，需用户主动开始。

通知权限只用于用户开启的每日提醒；安装应用权限只用于用户确认的本应用更新；联网权限只用于更新；重启广播用于恢复提醒；不申请定位、通讯录、相机或广泛存储权限。

如需反馈，可在本仓库创建 Issue。请勿公开上传含个人备注的备份或截图。
